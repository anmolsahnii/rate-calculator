# Rate Calculator for Gmail

This Chrome extension reads the customer email currently open in Gmail and opens
the public Rate Calculator with the detected shipment details prefilled.

## Install

1. Open `chrome://extensions`.
2. Turn on **Developer mode**.
3. Choose **Load unpacked**.
4. Select the `outputs/rate-calculator-chrome` folder.
5. Pin **Rate Calculator for Gmail** to the Chrome toolbar.

Refresh Gmail once after installing. Open a quote email and click the extension
button. Complete emails open the calculated quote automatically; incomplete
emails stay in the popup for review.
