# 3Myle Floating Quote Note

Version 1.1.2: the X button closes the note. Click the extension toolbar icon to reopen it. Closing keeps it hidden while you navigate Gmail; refreshing Gmail opens it again.

1. In Chrome open chrome://extensions (Edge: edge://extensions).
2. Enable Developer mode, choose Load unpacked, and select this folder.
3. Refresh Gmail. The quote note appears in the bottom-right corner automatically.
4. Open your email and click Analyze email on the note.

If an earlier version is already installed from this folder, click Reload on its extension card and refresh Gmail. Version 1.1.1 also starts the note in Gmail tabs that were already open when installed. If the note is missing, click the extension toolbar icon to start it. Drag the yellow title bar to move the note. The minus button minimizes it; plus expands it. No separate tab, sidebar or pasted email is needed.

Rates load from the same GitHub Pages project each time Gmail loads. The note uses the calculator's pricing functions, customer cards and fuel rules. It needs internet access. When fuel cannot refresh, it shows a dated saved schedule and requires a review before copying.

Pickup defaults to Mississauga and pricing defaults to Spot, using the same calculator functions, fuel rules and market adjustment. The detected client is shown separately; another customer agreement can be selected when needed. Extraction recognizes text patterns, sender names/domains, labelled routes, quantities, dimensions and pallet/length/width/height/weight tables in inches. It is not a general AI email reader. Review the editable fields. Attachments and images are not parsed. Multi-shipment emails, missing values, special services and oversized freight need review.

The assistant reads the last expanded Gmail message only when you click Analyze email. If that reply supplies dimensions but omits the delivery address, it can recover the labelled destination from quoted text in the same message and flags this for review. Older quantities do not override the updated load. Moving to another email clears the previous quote until you click again. It does not scan unopened messages, create drafts, send replies, or save raw email text. Email text stays in browser memory and is passed to the hosted rate panel; only fuel-source requests leave the panel. Copy quote puts the reviewed price on your clipboard.

The note appears automatically in Gmail after the one-time extension installation. It remains visible within Gmail, not above unrelated Windows applications.
