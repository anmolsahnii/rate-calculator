# 3Myle Floating Quote Note

1. In Chrome open chrome://extensions (Edge: edge://extensions).
2. Enable Developer mode, choose Load unpacked, and select this folder.
3. Refresh Gmail. The quote note appears in the bottom-right corner automatically.
4. Open your email and click Analyze email on the note.

If version 1.0 is already installed from this folder, click Reload on its extension card and refresh Gmail. Drag the yellow title bar to move the note. The minus button minimizes it; plus expands it. The extension toolbar icon also expands it. No separate tab, sidebar or pasted email is needed.

Rates load from the same GitHub Pages project each time Gmail loads. The note uses the calculator's pricing functions, customer cards and fuel rules. It needs internet access. When fuel cannot refresh, it shows a dated saved schedule and requires a review before copying.

Extraction currently recognizes text patterns, sender names/domains, labelled routes, quantities and dimensions. It is not a general AI email reader. Review the editable fields. Attachments and images are not parsed. Multi-shipment emails, missing values, special services and oversized freight need review. Customer names in a delivery address alone do not select the billing customer.

The assistant reads the last expanded Gmail message only when you click Analyze email. Moving to another email clears the previous quote until you click again. It does not scan unopened messages, create drafts, send replies, or save raw email text. Email text stays in browser memory and is passed to the hosted rate panel; only fuel-source requests leave the panel. Copy quote puts the reviewed price on your clipboard.

The note appears automatically in Gmail after the one-time extension installation. It remains visible within Gmail, not above unrelated Windows applications.
