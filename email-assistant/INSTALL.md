# 3Myle Email Quote Assistant

1. In Chrome open chrome://extensions (Edge: edge://extensions).
2. Enable Developer mode, choose Load unpacked, and select this folder.
3. Refresh your Gmail tab. Pin 3Myle Email Quote Assistant from the browser's Extensions menu.
4. Click the pinned icon once to open the sidebar, then open an email in Gmail.

The sidebar follows the last expanded message in the current Gmail conversation. Close older replies when you want to quote a particular message. Pause Follow email to edit a quote without navigation replacing your work. Resume it to read the current email again.

Rates load from the same GitHub Pages project each time the sidebar opens. The panel uses the calculator's pricing functions, customer cards and fuel rules. It needs internet access. When fuel cannot refresh, it shows a dated saved schedule and requires a review before copying.

Extraction currently recognizes text patterns, sender names/domains, labelled routes, quantities and dimensions. It is not a general AI email reader. Review the editable fields. Attachments and images are not parsed. Multi-shipment emails, missing values, special services and oversized freight need review. Customer names in a delivery address alone do not select the billing customer.

The assistant reads the open message only while the sidebar is following Gmail. It does not scan unopened inbox messages, create drafts, send replies, or save raw email text. Email text stays in browser memory and is passed to the rate panel; only fuel-source requests leave the panel. Copy quote puts the reviewed price on your clipboard.

Browser extensions require this one-time installation. The browser may ask you to open the panel again after a restart; this is a browser sidebar, not a Windows always-on-top window. Closing the panel stops reading messages.
